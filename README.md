# 1021

Open `index.html` to start the birthday surprise. After the nickname prompt, the experience is split into these pages:

- `birthday.html` — the birthday greeting and link to the next surprise.
- `memory-wall.html` — the interactive scrapbook, memories, and other birthday surprises.

The birthday and memory-wall pages use separate stylesheets (`birthday.css` and `memory-wall.css`).
